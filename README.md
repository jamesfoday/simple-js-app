# Pokémon App

## Project Description
The Pokémon App is a simple web application that allows users to browse a list of Pokémon and view their details. It uses the PokéAPI to fetch data about various Pokémon, including their names, images, and heights. The app is built using HTML, CSS, and JavaScript, with the assistance of Bootstrap for styling and layout.
